## 1. Chrome Web Store 掲載文

### 短い説明 (132文字以内)
Twitchのフォロー中配信を自動巡回・スマート表示し、カスタムCSS/JSの適用も可能なミニマルビューア拡張機能です。

### 詳細説明
**GNB Twipper** は、Twitchの配信視聴体験を最適化するために開発されたChrome拡張機能です。自動巡回（オートローテーション）機能とミニマルなUI拡張を提供します。

#### 主な特長:
- 🔄 **スマート自動巡回モード**: フォロー中のライブ配信者を、スマートキューと目標視聴時間に基づいて自動で巡回・切替します。
- 🚫 **巡回除外設定**: 自動巡回から特定のチャンネル（公式音楽配信や24時間配信など）を簡単に除外登録可能。
- 🎨 **カスタムCSS/JS/HTML埋め込み**: TwitchのUIスタイル変更や独自のDOM要素をデスクトップ視聴環境に合わせて自由に追加・カスタマイズ。
- ⚡ **軽量・高速動作**: Svelte 5 と Manifest V3 で構築された軽快な動作。
- 🌐 **多言語対応**: 英語・日本語に完全対応。

## 申請時に使用する使用権限 (Permissions) の理由説明書

ストア審査提出時、`manifest.json` で要求している各権限の用途について以下の通り説明を入力してください:

| 権限 (Permission) | 申請理由・使用目的 |
| :--- | :--- |
| `storage` | ユーザーの設定（巡回間隔、除外チャンネル一覧、カスタムCSS/JSコードなど）をブラウザ内にローカル保存するため。 |
| `alarms` | CPU負荷をかけずに高精度な自動巡回タイマー処理を実行するため。 |
| `scripting` | ユーザーが指定したカスタムCSS/JSスクリプトを `twitch.tv` ページ内に安全に注入するため。 |
| `activeTab` | 自動巡回時に現在表示中のTwitchタブのURLおよび画面遷移を行うため。 |
| `cookies` | タブ切り替え時やセッション修復時にTwitchログイン状態を安全に維持するため。 |
| `tabs` | 自動巡回の切り替え操作、およびチャット・プレイヤーウィンドウの連携制御のため。 |
| ホスト権限: `https://www.twitch.tv/*`, `https://gql.twitch.tv/*` | TwitchのウェブUIおよびFollow一覧取得API/GQLと通信を行うため。 |
