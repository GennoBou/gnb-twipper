```text
GNB Twipper for Twitch is a minimalist browser extension designed to help you efficiently watch and rotate through live streams of your followed Twitch channels.

[Key Features]
- 🔄 Smart Channel Auto-Rotation & Standby: Automatically switches between live followed channels on a timer. When only 1 channel is live, rotation automatically pauses so you can keep watching, and resumes automatically when 2 or more channels go live.
```

## 🔒 Publishing Scope (Limited / Unlisted / Hidden Publication)

To publish as a **Limited / Unlisted / Hidden** extension (accessible only via direct link and excluded from public store search):

### Chrome Web Store
1. In Chrome Developer Dashboard, navigate to **Distribution -> Visibility**.
2. Select **Unlisted**.
3. Only users with the direct store link will be able to view and install the extension; it will not appear in public search results.

### Microsoft Edge Add-ons
1. In Microsoft Partner Center, navigate to your extension's **Availability -> Visibility**.
2. Select **Hidden** (make this product hidden in the store / accessible only via direct URL).
3. Only users with the direct Edge Add-ons link will be able to view and install the extension.

## 🧪 Notes for Certification (Reviewer Testing Guide)

Paste the following template into the **Notes for certification** field on Microsoft Partner Center (and reviewer note fields on Chrome Web Store / Firefox AMO):

```text
Extension Overview:
GNB Twipper for Twitch injects a minimalist control bar next to the search bar on Twitch (https://www.twitch.tv/) and provides a browser action popup and options page so users can automatically rotate through live channels they follow.

How to Test:
1. Install the extension and open https://www.twitch.tv/.
2. Observe the injected GNB Twipper control bar next to the top search bar (or click the extension toolbar icon to open the popup).
3. To test live stream rotation, sign in with any standard Twitch account that follows at least 2 currently live channels, then click the "AUTO" button or the "Skip" button in the control bar/popup. The extension fetches live status via Twitch's official GraphQL API (or falls back to the sidebar DOM) and navigates smoothly between live followed streams without cluttering browser history.
4. Even without signing in to a Twitch account, you can verify the injected header control bar on Twitch.tv, open the toolbar popup, and open the Options page to configure rotation intervals, excluded channels, display language, and optional custom CSS.

Notes on Credentials & Permissions:
- No dedicated test account is provided because the extension works with any standard user Twitch account and stores all settings strictly locally in browser storage without any external backend server or third-party tracking.
- The optional "userScripts" permission is only used for advanced users who explicitly configure custom JavaScript for Twitch.tv and enable "Allow user scripts" in the browser's extension details page. Core rotation features work completely without enabling user scripts.
```

## Required Permissions Justification

When submitting to store reviewers, provide the following justifications for permissions used in `manifest.json`:

**Single Purpose**: Automatically cycle through and control playback of live streams followed on Twitch.

| Permission | Justification / Purpose |
| :--- | :--- |
| `storage` | Save user preferences, rotation interval settings, and channel exclusion lists locally. |
| `alarms` | Manage precise timers for channel rotation without degrading CPU efficiency. |
| `userScripts` | Safely execute user-defined custom JavaScript logic in compliance with browser security specifications. |
| `cookies` | Maintain session state and seamless streaming experience across tab switches. |
| `tabs` | Handle Twitch player and chat window navigation for automated hopping. |
| `webRequest` | Automatically detect valid Twitch Client-ID headers from GraphQL requests to ensure stable stream status retrieval. |
| Host: `https://www.twitch.tv/*`, `https://gql.twitch.tv/*` | Interact with Twitch Web UI and Twitch GQL API to retrieve follow lists and stream status. |
