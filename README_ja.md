# GNB Twipper for Twitch

> **Twitchのフォロー中チャンネルを自動巡回・快適視聴できる Chrome 拡張機能**

---

## 💡 GNB Twipper とは？

`GNB Twipper` は、Twitch でフォローしている配信者を一定時間ごとに自動で切り替えて巡回・視聴するための Google Chrome 拡張機能です。

ブラウザの既存のログインセッションをそのまま利用するため、面倒なアカウント連携やログイン情報の再入力は一切不要。Twitch のセキュリティ保護を侵害することなく、安全かつ軽快に動作します。

「推しの配信をまんべんなく見守りたい」「作業用BGMとしてフォロー中の配信を自動で流し見したい」という方に最適です。

---

## ✨ 主な機能

### 🔄 スマート自動巡回（オートモード）
- **一定間隔で自動切り替え**: 設定した時間（例: 3分）ごとに、ライブ配信中のフォロー中チャンネルを順次切り替えます。
- **スマート待機機能**: 
  - 配信者が1人のみの場合はページ遷移をストップし、そのまま視聴を継続します（「待機中 (1人のみ)」）。
  - 他の配信者がライブを開始して2人以上になると、自動的に巡回を再開します。
  - 配信者が0人の場合は「待機中 (配信なし)」として待機します。

### 🚫 サブスク限定配信の自動スキップ
- 未加入の「サブスクライバー限定配信」を自動検知してスキップします。
- **無料プレビュー対応**: 無料プレビュー期間中はそのまま視聴を継続し、無料枠が終了して画面がロックされた瞬間に次へスキップする設定も可能です。

### ⛔ 巡回除外チャンネル設定
- 24時間配信チャンネル、公式音楽配信、巡回したくない配信者などを除外リストに登録し、巡回キューから安全に除外できます。

### 🖥️ Twitch 画面に溶け込む操作バー (`GnbNavTrigger`)
- Twitch の画面上部（検索バーの横）にコンパクトな専用操作バーが埋め込まれます。
  - **[AUTO 開始 / 停止]**: ワンクリックで自動巡回をトグル。
  - **[スキップ]**: 今の配信を飛ばして次の配信者へ即座にジャンプ。
  - **タイマー＆ステータスバッジ**: 次の巡回までの残り時間や待機ステータスを表示。
  - **配信者リストのアコーディオン表示**: 巡回対象の配信者一覧と視聴進捗をその場で確認・直接切り替え。

### 🚀 起動時オート巡回の自動開始 (`autoStartOnLogin`)
- ブラウザや Twitch を開いた際に、手動でボタンを押すことなく自動で巡回を開始する設定が可能です。

### 🎨 カスタム CSS / JS インジェクション（上級者向け）
- Twitch ページ上にユーザー独自の CSS スタイルや JavaScript ロジックを動的に適用できます。
- 設定画面のエディタから、構文チェック付きで安全にカスタマイズ可能です。
- ⚠️ **JavaScript 実行に関する注意**: ブラウザのセキュリティ仕様（Manifest V3 `userScripts` API）により、カスタム JavaScript を実行するには、ブラウザの拡張機能管理ページ（`chrome://extensions` や `opera://extensions`）で本拡張機能の **「詳細」** を開き、**「ユーザースクリプトを許可する」** を ON に設定する必要があります。

## 📥 インストール方法

### Chrome ウェブストア（準備中）
ストア公開後はワンクリックでインストールできるようになります。

### ZIP ファイルから手動でインストールする場合
1. [GitHub Releases](../../releases) から最新の `chrome-extension-vX.X.X.zip` をダウンロードします。
2. ダウンロードした ZIP ファイルを任意のフォルダに解凍します。
3. Google Chrome を開き、アドレスバーに `chrome://extensions/` と入力して開きます。
4. 画面右上の **「デベロッパーモード」** を ON にします。
5. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、解凍したフォルダ内の `dist` フォルダ（または解凍先フォルダ）を選択します。
6. [Twitch](https://www.twitch.tv) にアクセスすると、画面上部に GNB Twipper の操作ボタンが表示されます。

## 🚀 かんたん使い方ガイド

1. **Twitch を開く**: 普段お使いのアカウントでログイン済みの Chrome で [Twitch](https://www.twitch.tv) を開きます。
2. **巡回を始める**:
   - 画面上部検索バー横の **`[AUTO]`** ボタン、または拡張機能アイコンのポップアップから「オート巡回開始」を押します。
   - タイマーのカウントダウンが始まり、フォロー中のライブ配信者を自動巡回します。
3. **操作する**:
   - 次の配信者へすぐに移動したいときは **`[スキップ]`** を押します。
   - 巡回を一時停止したいときは **`[AUTO (停止)]`** を押します。

## ⚙️ 設定項目

拡張機能アイコンをクリックして「詳細設定」を開くか、上部バーの設定アイコンから各種カスタマイズが可能です。

| 設定項目 | 説明 | デフォルト |
| :--- | :--- | :--- |
| **巡回切り替え時間** | 通常巡回時に次の配信者へ切り替えるまでの時間（分） | 3分 |
| **初回目標視聴時間** | 配信者を最低限視聴する目標時間（連続視聴記録等の維持用） | 6分 |
| **起動時オート開始** | Twitch/ブラウザ起動時に自動で巡回を開始するかどうか | OFF |
| **サブスク限定スキップ** | 未加入のサブスク限定配信を自動的にスキップするかどうか | ON |
| **無料プレビュー視聴** | サブスク限定配信の無料視聴期間中はスキップせず視聴を続けるか | ON |
| **巡回除外チャンネル** | 巡回対象から除外したいユーザーIDやURLを登録 | なし |
| **カスタム CSS / JS** | Twitch ページに適用する独自スタイル・スクリプト | 無効 |
| **表示言語** | UI の表示言語（日本語 / English） | ブラウザ準拠 |

## ❓ よくある質問 (FAQ)

### Q. Twitch のユーザー名やパスワードを入力する必要はありますか？
**A.** 一切不要です。お使いのブラウザで既にログインしているセッション情報をそのまま活用して動作します。パスワードや認証トークンを外部サーバー等に送信することは一切ありません。

### Q. アカウントが BAN されたりペナルティを受けたりしませんか？
**A.** 通常のブラウザ閲覧と同じ手順で配信ページを開いて視聴するため、Twitch のセキュリティ保護（Twitch Integrity）を侵害しません。通常のユーザー操作を自動化しているだけですので、安心してお使いいただけます。

### Q. 巡回が途中で止まってしまいました。
**A.** ライブ配信中のフォロー中チャンネルが1人のみの場合、自動巡回は一時停止して「待機中 (1人のみ)」になります。他の配信者がライブを開始すると自動で巡回が再開されます。
